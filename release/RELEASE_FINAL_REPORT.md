## 4. Residual issues + fixes

### Fixed in this pass (trivial fixes the verifiers found)
1. **`README.md` venv command** — `python -m venv` → `python3 -m venv` (stock Ubuntu/Debian lacks a `python` alias until the venv activates; was a first-step blocker for a naive user). **Fixed.**
2. **Pure-bottleneck fine-tuned W-F1 — verified 0.883 (paper is correct).** A verifier's fresh recompute reported 0.867, but the authoritative artifact `outputs/residual_cbm/results_ft_last4.json` gives per-seed pure_bottleneck wf1 {0.853, 0.891, 0.889, 0.907, 0.871, 0.886} → **6-seed mean 0.883**, matching the paper. The 0.867 recompute was erroneous and has been REVERTED to 0.883 across README (×2), `accuracy_by_abnormality.md/.csv`. Lesson: report the shipped-artifact value, do not overwrite it with an unverified fresh-training recompute. Other three heads reproduce cleanly (backbone 0.925, CEM 0.915, PCBM-h 0.917). **Corrected.**
3. **`compute_acceptance.py` bare `matplotlib` import** — crashed with `ModuleNotFoundError` (matplotlib intentionally not in the core CPU requirements). Wrapped in a `try/except ImportError` that raises a clear message pointing to `results/reproduce_paper.py` (which needs neither matplotlib nor the unshipped inputs). **Fixed.**
4. **`--out` naming looked directory-shaped but writes a file** — README/PAPER_NUMBERS examples changed to `runs/residual_cbm_ft.json` so the filename matches the actual single-JSON output. **Fixed.**
5. **`residual_cbm.py --backbone_tag` default `"frozen"`** — mislabelled output of the shipped fine-tuned bank; default changed to `"ft"`. **Fixed.**
6. **Stale `outputs/residual_cbm/results.md` provenance strings** (not a shipped file) — repointed to `code/residual_cbm.py` / `residual_cbm.py 6-seed mean` in `accuracy_by_abnormality.md` (×4) and `.csv` (bulk). **Fixed.**

### Residual (disclosed, non-blocking — by design)
